Class MarkovChainBatch<T>

Batch builder for efficient bulk operations on Markov Chains. All operations are queued and applied in a single clone operation.

Example

const chain = new MarkovChain({ seed: 1 });
const updated = chain.batch()
  .addSequence(['a', 'b', 'c'])
  .addSequence(['d', 'e', 'f'])
  .addEdge(['a', 'b'], 'x', 'y', 2)
  .commit();
